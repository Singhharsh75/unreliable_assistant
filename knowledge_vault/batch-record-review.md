# Batch Record Review

Every lot has an executed batch record (EBR). The batch record review is step 1 of lot release, see [[sop-lot-release]].

Production reviews the EBR first, within 2 working days of the end of manufacture. QA then performs an independent second review.
The reviewer checks that every step is signed and dated, every recorded value is within its limit, and every correction follows [[policy-data-integrity]].

Missing signatures, unexplained gaps, or values outside limits are review findings. A finding that cannot be explained by documentation is raised as a deviation, see [[sop-deviation]].
The review is complete only when all findings are closed and QA has signed the review page.
Target cycle time from end of manufacture to completed review is 5 working days.
