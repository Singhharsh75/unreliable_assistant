# Product Recall

A recall removes distributed product from the market. It is decided by the Recall Committee, chaired by the Head of Quality.

Recall classes: Class I (risk of serious harm or death), Class II (risk of temporary or reversible harm), Class III (unlikely to cause harm).
The regulator is notified within 24 hours for a Class I recall and within 72 hours for Class II and Class III.

Distribution records must allow every customer who received the lot to be identified within 4 hours, see [[sop-shipping]].
Initiating a recall changes lot status to RECALLED and is a Tier 3 action, see [[policy-hitl-approval]].
A mock recall is run once a year for one randomly chosen lot to test the 4-hour trace.
